| Operator | Meaning             | Example  | Result  |
| -------- | ------------------- | -------- | ------- |
| `==`     | equal hai?          | `8 == 8` | `true`  |
| `!=`     | equal nahi hai?     | `8 != 5` | `true`  |
| `>`      | bara hai?           | `10 > 5` | `true`  |
| `<`      | chota hai?          | `10 < 5` | `false` |
| `>=`     | bara ya equal hai?  | `8 >= 8` | `true`  |
| `<=`     | chota ya equal hai? | `8 <= 8` | `true`  |
